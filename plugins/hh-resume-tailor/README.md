# hh-resume-tailor

Плагин для Claude Code на русском языке. Разбирает резюме и подгоняет его сразу под несколько вакансий hh.ru.

Как работает: вы даете резюме (текстом, PDF или DOCX) и от двух до пяти ссылок на вакансии. Плагин читает вакансии, сводит в таблицу требования, общие для них, отмечает, что из этого есть в резюме, что описано другими словами и чего нет. Затем предлагает правки пунктов опыта в формате "было / стало" и пишет важные термины в нескольких формах.

Опыт, инструменты и цифры плагин не выдумывает. Если в вакансиях часто встречается то, чего в резюме нет, он задает вопрос и вписывает только после ответа.

Скилл: `rezume-pod-vakansii`. Запрос для начала: "Улучши мое резюме под эти вакансии" и ссылки.

A Russian-language Claude Code plugin that reviews a resume and tailors it to several hh.ru job postings at once without inventing experience.
