# Резюме под вакансии hh.ru

Плагин для Claude Code. Даете ему резюме и несколько вакансий с hh.ru, он находит требования, общие для этих вакансий, показывает, каких ключевых слов не хватает в резюме, и переписывает пункты опыта под них.

Опыт плагин не выдумывает. Если в вакансиях часто встречается то, чего в резюме нет, он спрашивает, было ли у вас такое, и вписывает только после ответа.

## Что получится

- Таблица требований: что встречается в двух и больше вакансиях, что из этого есть в резюме, что есть другими словами, чего нет.
- Разбор резюме: заголовок, опыт, навыки, раздел "О себе".
- Правки в формате "было / стало" с указанием, в какое место резюме они идут. Важные термины в нескольких написаниях (A/B-тесты и A/B-тестирование, CustDev и кастдев), потому что работодатель ищет резюме одним из вариантов, и заранее не знаете каким.
- Вопросы к вам про недостающий опыт и цифры.
- Акценты под каждую вакансию: что поднять повыше или упомянуть в сопроводительном письме.
- По желанию обновленное резюме целиком в файле, чтобы переносить на hh по разделам.

## Установка

Нужен Claude Code. В терминале:

```bash
claude plugin marketplace add Dariap5/hh-resume-tailor
```

```bash
claude plugin install hh-resume-tailor@offer-agent
```

## Как пользоваться

Откройте Claude Code и напишите, например:

```
Улучши мое резюме под эти вакансии: https://hh.ru/vacancy/... https://hh.ru/vacancy/... https://hh.ru/vacancy/...
Резюме в файле resume.pdf
```

Резюме можно вставить текстом, дать файлом PDF или DOCX. Резюме на hh обычно закрыто для чужих, поэтому проще скачать его с hh в PDF. Вакансий лучше от двух до пяти: по ним видно, что рынок ждет от должности, а не от одной компании.

## Что плагин делает и не делает

- Плагин открывает только те страницы вакансий, которые вы дали, по одному разу и с паузой.
- Резюме никуда не отправляет, оно остается в вашей сессии Claude.
- Ничего не меняет на hh.ru сам: правки вы переносите в резюме сами.
- Не называет "шанс пройти ATS" в процентах. Такой цифры снаружи никто не знает, плагин просто считает, сколько требований из вакансий видно в резюме до и после правок.

## Если хочется, чтобы поиск шел сам

Этот плагин делает одну вещь: готовит резюме. Если нужно, чтобы каждый день шли отклики на hh.ru с письмами под каждую вакансию, резюме поднималось в поиске, а переписка с рекрутерами не терялась, это делает [Офферный агент](https://offer-agent.dariyap.ru).
